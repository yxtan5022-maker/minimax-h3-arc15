# 研究路线图

| 里程碑 | 内容 | 状态 |
|---|---|---|
| M0 | 环境摸底（硬件/软件/凭据） | ✅ 完成（2026-08-08） |
| M1 | ComfyUI + IPEX/XPU 跑通小模型基线 | ⏳ 准备中 |
| M2 | 模型下载 + 量化研究（INT4/GGUF） | 待开始 |
| M3 | 全链路加载调试（加载/VAE/编码器） | 待开始 |
| M4 | 组合拳：XPU + INT4 + 页文件 + 组卸载 | 待开始 |
| M5 | 首个 480p 短片出片 | 待开始 |
| M6 | 提速优化（分辨率/步数/缓存）与长视频 | 待开始 |
| M7 | 完整复现文档 + 社区分享 | 待开始 |

## 决策门槛（Go / No-Go）

| 触发条件 | 决策 |
|---|---|
| M1 失败：IPEX 装不上 / 核显 XPU 不可用 | 放弃路径 A，转 B（纯 CPU 量化推理） |
| M2 无可用 INT4 / 质量不可接受 | 转路径 C（INT8 + 页文件 + 流式） |
| M3 全链路无法加载 | 检查页文件/内存，降级为单 VAE 调试 |
| M5 出片但 >12h/镜头 | 降级为"极慢演示"，记录数据后收尾 |
| M5 出片且 <6h/镜头 | 进入 M6 优化循环 |

## 每轮实验标准流程

1. 在 [experiments-log.md](experiments-log.md) 记"目的 + 配置"
2. 跑 `scripts/env-check.ps1` 记录基线快照
3. 执行实验，抓全报错原文
4. 记录耗时 / 显存 / 内存 / 结果
5. 更新文档结论与下一步
